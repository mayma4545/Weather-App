| Browser → `POST /api/weather/predict-planting` | Untrusted JSON body (cropKey, language, forecastData) |
| Route → geminiService → Google API | Server-side only; session must be valid |
| Route → Browser JSON | Model text enters recommendations[] (XSS handled in Plan 03) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | E (Elevation of Privilege) | `POST /api/weather/predict-planting` | mitigate | Add `requireAuth`; unauthenticated callers get 401 JSON |
| T-07-06 | T (Tampering) | `cropKey` / `language` body fields | mitigate | sanitizeInput + cropKey allowlist; language enum coerce to filipino\|english |
| T-07-07 | I (Information Disclosure) | Error / response payload | mitigate | Never put API key in response; `recommendations_error` is short code only; console.warn message only |
| T-07-08 | D (Denial of Service) | Gemini latency / quota | mitigate | try/catch fallback to static recommendations so HTTP still 200 with usable advice; optional 3s per-user skip; 12s timeout in service |
| T-07-02 | Prompt injection | forecastData / alerts into evaluation | mitigate | Allowlisted cropKey; evaluation built by rule engine; geminiService prompt boundaries from Plan 01; do not forward raw unsanitized user essays (there is no free-text chat field) |
| T-07-09 | R (Repudiation) | AI vs static source | mitigate | `recommendations_source` field for client transparency / debugging |
